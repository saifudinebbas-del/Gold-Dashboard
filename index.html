Konfigurasi data automatik

Versi ini menggunakan endpoint Twelve Data untuk candle XAU/USD. Dapatkan API key sendiri dan semak sama ada pelan anda menyokong XAU/USD, interval 5min/15min/1h serta akses dari pelayar. Kunci disimpan hanya pada peranti ini, tetapi permintaan dibuat terus dari browser; jangan guna kunci sensitif/berbayar yang tidak selamat didedahkan di browser. Untuk penggunaan serius, gunakan backend proxy.
